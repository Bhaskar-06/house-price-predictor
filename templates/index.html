How it works

A complete predictive-analytics pipeline from raw data to live prediction.

🧹

1. Data cleaning

Missing values, mixed units and outliers are removed so the model learns real market patterns.

🛠️

2. Feature engineering

Text such as "3 BHK" is converted to numbers and rare localities are grouped together.

🤖

3. Gradient boosting

Tuned with cross-validation and trained on log-prices for stable, accurate estimates.

🚀

4. Live deployment

Served through a Flask API and deployed on the cloud for instant predictions.
